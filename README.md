# DCM 연동 현황 대시보드 — GitHub Pages 배포본 v8

## 핵심 계산 기준
- 전체 연동률 = O / (O + X). 카드에 **법인별 평가 총수 중 O 몇 처인지** 함께 표시합니다.
- 연동 필요 평가처수 = 대웅제약/대웅바이오/한올바이오의 X 합계.
- 연동 필요 절대처수 = 업체/권역별로 X가 하나라도 있는 실사업자번호를 중복 제거한 수. 같은 실사업자번호가 서로 다른 도매업체에 있으면 각각 1처로 계산.
- 공급 절대처수 = 업체/권역별로 3개 법인 중 하나라도 O/X가 있는 실사업자번호의 고유 수. 같은 실사업자번호가 서로 다른 도매업체에 있으면 각각 1처로 계산.
- 공급 절대처수 변화 = 전월 공급 절대처수 대비 당월 증감 처수와 증감률.
- X→O / O→X = 법인 단위 변화 건수.
- 신규 공급처수 = 업체/권역+실사업자번호 기준으로 전월에 3개 법인이 모두 미공급이고 당월에 하나라도 O/X가 된 공급처를 1처로 카운트.
- 공급 중단처수 = 업체/권역+실사업자번호 기준으로 전월에 하나라도 O/X가 있고 당월에 3개 법인이 모두 미공급이 된 공급처를 1처로 카운트. 공급 중단 상세에서 기존 O/X를 확인 가능.

### 중요 검증 — 백제약품 원주 2026년 6월→7월
신규 공급처수와 공급 중단처수는 공급 절대처수와 동일한 업체/권역+실사업자번호 기준을 사용하므로 `신규 - 중단 = 공급 절대처수 증감`이 항상 일치합니다.
- 1938801973: 한올바이오 미공급→O
- 2248165059: 한올바이오 미공급→X
- 6708702429: 대웅제약 O / 대웅바이오 O / 한올바이오 X 신규 → 법인 3건이어도 1처

2026년 7월 백제약품 원주 전체 연동률은 **법인별 평가 20처 중 O 14처 = 70.0%**입니다.
공급 절대처수는 6월 18처 → 7월 9처로 **-9처 (-50.0%)**입니다.

## 월별 사용
1. 상단 `월별 Excel 업데이트`에서 파일을 선택합니다. 여러 파일 동시 선택 가능.
2. `6월`, `7월`, `8월`처럼 `숫자+월` 시트를 자동 인식합니다.
3. 필수 열: `도매상명`, `실사업자번호`, `실사업자명`, `대웅제약`, `대웅바이오`, `한올바이오`.
4. 파일명 `...2608...xlsx`는 2026년 8월 파일로 연도를 인식합니다.
5. 같은 월+업체/권역을 다시 업로드하면 해당 범위를 새 파일로 교체합니다.
6. 브라우저 로컬 저장을 사용하므로 PC/브라우저 이동 시 `JSON 백업` 기능을 이용하세요.

## GitHub Pages 배포
1. ZIP 압축 해제 후 **내용물 전체**를 저장소 루트에 업로드합니다.
2. `index.html`이 저장소 최상위에 있어야 합니다.
3. `Settings → Pages → Deploy from a branch → main / (root)` 설정.
4. `.nojekyll` 포함.
